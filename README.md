# UserBase

## A new social network created as a pet project

### Instruction for setup

1. Clone repository
    ```
    git clone https://github.com/igorehkere/UserBase.git
    ```

2. Install pnpm packet manager
    ``` 
    npm install -g pnpm
    ```

3. Install dependencies
    ```
    pnpm install
    ```

4. Add file with env

5. Create local database PostgeSQL

6. For running dev mode:
    ```
    pnpm dev
    ```
7. For running production mode:
    ```
    pnpm start
    ```
